# Diretrizes de UI/UX do Projeto

## Stack Visual
- Estilo: Minimalismo funcional e estético (referência: Linear / Vercel).
- Cores: Dark Grafite profundo (sem azulado) como fundo, texto principal Off-White, cinzas neutros para bordas (1px). Cor de destaque pontual: Verde Floresta (#1b4332).
- Espaçamento: Uso agressivo de whitespace (paddings generosos).

## Integração Mobbin MCP
- Sempre que eu pedir uma nova tela ou componente, use o Mobbin MCP para pesquisar fluxos reais de mercado.
- Evite criar soluções de interface hipotéticas; prefira replicar a hierarquia e os padrões estruturais de apps consolidados que você encontrar na API do Mobbin.
